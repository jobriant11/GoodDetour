Privacy policy

Good Detour is designed so your redirect choices and browsing behavior do not need to leave your browser.

What the extension stores

The extension stores the redirect rules you create, your pause-page preferences, whether redirects are enabled, and a total count of pause pages shown. Chrome stores this information locally in the extension's private storage on your device.

What the extension does not collect

This version does not send visited domains, URLs, redirect rules, browsing history, page content, identifiers, or the local pause count to the developer or any third party. It contains no analytics, advertising, or tracking SDK.

Permissions

Good Detour requests access to a domain only after you add that domain as the source of a redirect. That access is used to apply the redirect you requested. The extension uses Chrome's declarative network request system so the browser can perform the redirect without giving the extension the contents of each network request.

Sharing and sale

Good Detour does not sell, rent, share, or transfer user data. Browsing activity is not used for advertising, profiling, creditworthiness, or any unrelated purpose.

Your choices

You may turn off a rule, turn off all redirects, export or delete your rules, revoke site access in Chrome, or uninstall the extension. Uninstalling removes the extension's local storage according to Chrome's behavior.

Future changes

If a future version introduces optional remote features, it will explain the data involved in the product interface before collection and request affirmative consent where required. Material privacy changes will not be applied retroactively without notice and any required consent.

Chrome Web Store Limited Use

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

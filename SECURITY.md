# Security policy

Good Detour handles browser navigation and treats vulnerabilities as high impact.

Do not open public issues for suspected vulnerabilities. Use GitHub's private vulnerability reporting for this repository, or first contact admin@productlab.ai with the subject “Good Detour security.” Include the affected version, reproduction steps, and impact, but never include real browsing history, credentials, sensitive URLs, or working exploit details in an initial email.

The latest released version receives security fixes. Older versions are not supported.

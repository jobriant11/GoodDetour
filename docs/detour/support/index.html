Support

How can we help?

Good Detour is open source. Search existing reports or open a new issue with reproducible, privacy-safe details.

Protect your privacy: never post private, intranet, authentication, account, or sensitive URLs. Replace them with example.com-style placeholders.

Private support

Email admin@productlab.ai for private support, legal, or privacy questions. Include only the information needed to answer your request.

Common fixes

Reload the extension after updating an unpacked build. Confirm the source site's permission was granted. Check that redirects are globally enabled and the individual rule is on. Export a backup before reinstalling.

Report a problem

Open a bug report

Share feedback

Ideas about features, usability, destinations, privacy, or trust are welcome. Feedback is public, so use placeholder URLs and omit browsing history or account details.

Open the feedback form

Delete extension data

Good Detour has no developer-run account. In the extension, open Settings → Privacy & data to delete the shared Chrome Sync copy or reset data on the current browser. Public GitHub feedback must be edited or deleted through GitHub.

Security

Do not publish suspected vulnerabilities. Follow the repository's security reporting policy or email admin@productlab.ai without sensitive exploit details.
